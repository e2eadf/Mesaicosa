# MESAICOSA — V1

Mens sana in corpore sano. Application web personnelle, installable et utilisable hors ligne.

- **Aujourd'hui** : la journée, créneaux à cocher, bascule télétravail, modification d'un jour précis.
- **Semaine** : vue d'ensemble et temps réalisé par domaine.
- **Gymnase** : dactylographie, calcul mental, géographie, lecture rapide.
- **Boussole** : objectifs (long terme, trimestre, semaine), revue hebdomadaire, priorités.
- **Données** : tout reste dans l'appareil ; partage d'une sauvegarde par Quick Share pour l'autre appareil.

Données géographiques : world-atlas (Natural Earth) et world-countries (licence ODbL).

Aucune donnée personnelle n'est contenue dans ce code : la semaine type, les domaines et les objectifs sont créés dans l'app ou importés via un fichier « paquet », et restent dans l'appareil.
